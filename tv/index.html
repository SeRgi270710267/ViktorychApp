Install TV app Open in browser

Version 1.0.0, about 0.5 MB.

On this TV

  1. Press Install TV app. The file downloads in a few seconds.
  2. Open the download. The first time, Android asks to allow installs from this app: choose Settings, turn on Allow from this source, then press Back.
  3. Press Install, then Open. The ViktorychApp icon is now in the Apps row on the home screen. Hold OK on it to move it to Favourites.

If the download does not open

  1. Install the free Downloader app (by AFTVnews) from Google Play on the TV.
  2. Open it and type viktorychapp.pages.dev/tv in the address box.
  3. Press Install TV app on this page, then follow step 2 above. Android asks once to allow installs from Downloader.

If Android shows no switch: open Settings › Apps › Security & restrictions › Unknown sources (on Fire TV: Settings › My Fire TV › Developer options › Install unknown apps), turn on the browser or Downloader, then try again.

Custom app name

Letters, numbers and spaces, up to 24 characters. Up to 3 builds a day. Sign in to ViktorychApp in this browser first.
